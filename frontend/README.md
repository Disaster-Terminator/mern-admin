# StudyHub Frontend

StudyHub 前端基于 React + Ant Design，提供课程管理、学习任务、学习笔记、复习计划、统计分析与 AI 学习助手页面。

## 可用命令

- 开发模式：`npm start`
- 生产构建：`npm run build`
- 单元测试：`npm test`

默认开发地址：`http://localhost:3000`

## 运行前要求

- 后端服务已启动并可访问
- 根目录 `.variables.env` 已完成数据库配置

更多整体说明请查看根目录 `README.md` 与 `docs/submission-guide.md`。

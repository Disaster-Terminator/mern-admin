# StudyHub 演示流程（手动稳定版）

> 当前仓库无现成 E2E 用例，本流程用于浏览器自动化录制、手动演示、截图与报告素材采集。

## 0. 启动服务

1. 后端：`npm start`
2. 前端：`cd frontend && npm start`
3. 打开：`http://localhost:3000`

## 1. 登录

1. 进入登录页。
2. 输入初始化管理员账号：`admin@demo.com`。
3. 输入密码：`123456`。
4. 点击“登录系统”。

截图点位建议：

- 登录页（显示 StudyHub 标题）
- 登录成功后的首页概览

## 2. 新建课程（Courses）

1. 左侧点击“课程管理”。
2. 点击“新增课程”。
3. 示例数据：
   - 课程名称：软件工程
   - 授课老师：王老师
   - 上课地点：A301
   - 上课星期：周二
   - 备注：团队项目课程
4. 提交。

截图点位建议：

- 课程列表中出现新课程

## 3. 新建学习任务（Tasks）

1. 左侧点击“学习任务”。
2. 点击“新增任务”。
3. 示例数据：
   - 任务标题：完成需求分析文档
   - 所属课程：软件工程
   - 截止日期：2026-04-20
   - 优先级：高
   - 状态：进行中
   - 备注：分三段完成
4. 提交。
5. 点击“快速切换”开关，把任务切到“已完成”（演示状态切换）。

截图点位建议：

- 任务创建后列表
- 状态切换前后各一张

## 4. 新建学习笔记（Notes）

1. 左侧点击“学习笔记”。
2. 点击“新增笔记”。
3. 示例数据：
   - 标题：需求建模课堂笔记
   - 所属课程：软件工程
   - 内容：记录用例图、领域建模和边界条件要点
   - 标签：需求,建模,用例图
4. 提交。

截图点位建议：

- 笔记列表与标签展示

## 5. 新建复习计划（Review Plans）

1. 左侧点击“复习计划”。
2. 点击“新增复习计划”。
3. 示例数据：
   - 课程：软件工程
   - 复习日期：2026-04-25
   - 复习目标：完成第 1-4 章重点回顾
   - 状态：未完成
   - 备注：先做思维导图
4. 提交。
5. 用“快速切换”把状态改成“已完成”。

截图点位建议：

- 复习计划列表
- 完成状态切换

## 6. 打开统计页（Statistics）

1. 左侧点击“数据统计”。
2. 确认以下区块有数据：
   - 课程总数、任务总数、已完成任务、笔记数量、AI 使用次数
   - 课程任务分布
   - 课程笔记分布
   - 任务状态统计

截图点位建议：

- 统计总览卡片
- 课程任务分布表

## 7. 打开 AI 助手（AI Assistant）

1. 左侧点击“AI 学习助手”。
2. 输入示例：
   - 课程名：软件工程
   - 任务描述：下周要交需求分析文档，时间不够
   - 笔记内容：已有用例图草稿和章节摘要
   - 输出模式：综合建议
3. 点击“生成 AI 结果”。
4. 观察结果区：
   - 若配置了 `OPENAI_API_KEY`，显示建议文本
   - 若未配置，显示“AI API 未配置”的友好提示

截图点位建议：

- AI 输入表单
- AI 输出结果或未配置提示
